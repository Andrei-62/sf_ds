### Описание проекта
Преобразование, исследование и очистка данных, котрыми является база резюме, выгруженная с сайта поиска вакансий hh.ru.

### Цель проекта
Анализ данных компании HeadHunter, которая хочет построить модель, которая бы автоматически определяла примерный уровень заработной платы, подходящей пользователю, исходя из информации, которую он указал о себе.

### Струкутра проекта

### Основные этапы проекта
1. Исследование структуры данных: прочитаны данные, выведена основная информация, выведена основная статистическая информация о столбцах.
2. Преобразование данных, в данном разделе проведена предобработка данных
3. Исследование зависимостей в данных, в данном разделе проведен разведывательный анализ (EDA)
4. Очистка данных
